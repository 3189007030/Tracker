# 独立线协议检查

`wirecheck.rs` 是可由 `rustc` 单独编译的 Rust 标准库程序，不使用 workspace、项目协议编解码代码或第三方 crate。只允许直接连接 `127.0.0.1` 或 `::1` 的 HTTP 18081（核心）或 18080（隔离 Nginx）与 UDP 16969，拒绝其他地址、端口和跨地址族组合。需要 Linux `/dev/urandom`。它仅用于启用了私网节点的隔离 Tracker，不能用于公开服务。IPv4、IPv6 需要分别运行；隔离实例的 HTTP 监听地址需要与相应命令匹配。工具不提供源地址伪造，也不连接或请求文件分块。

在拥有隔离服务的主机上由操作者编译和运行：

```sh
rustc --edition 2021 -O validation/wirecheck.rs -o /tmp/tracker-wirecheck
/tmp/tracker-wirecheck --self-test
/tmp/tracker-wirecheck --http 127.0.0.1:18081 --udp 127.0.0.1:16969
/tmp/tracker-wirecheck --http '[::1]:18080' --udp '[::1]:16969'
```

自检不发网络请求：对独立的 bencode 解析进行 512 个有限长度二进制字符串的生成、往返和全部截断点验证，以及数字、字典和尾随字节错误检查。网络检查使用硬编码 BEP 15 connect 报文验证事务；覆盖短包与伪造 cookie 无响应、单资源计数不变、UDP scrape 0/19/20 字节与 64/65 hash 边界、HTTP 19/20/21 字节 hash 与 0/64/65 hash scrape 边界、HTTP 200 内含 failure、`%00`/`%FF`/`+` 二进制查询、numwant 0、真实 HTTP/UDP 跨入口同 hash 互见、完整 IP:端口和去重、自身排除、停止后 2→1→0、另一个随机 hash 无关节点为空。仅观察自身测试 hash 的计数，不能在有并发其他客户端时将全局计数变化归因于此工具。

一次运行总截止时间小于 30 秒；每个套接字操作使用剩余时间内的有限超时。累计发送/读取的 HTTP 报文和 UDP 负载严格小于 256 KiB；这是应用层统计，不含 IP/TCP 头或系统重传。程序不打印 hash、地址、查询串、原始报文或错误详情；逐行 JSON 仅含固定阶段名、布尔值和最终字节数、耗时。失败返回非零退出码。异常时尽力通过 HTTP stopped 清理已登记的测试端口；进程被强制杀死或服务不可达时不能保证清理成功，应等待隔离实例状态过期或由操作者重置隔离实例。完成前不得将临时状态视为公开 Tracker 的真实节点。

该检查验证确定的协议和隔离环境下跨入口互见，不替代真实公网连通性、长时间保留、fuzz 测试或容量测试。不要与会修改这些测试 hash 的其他程序并行运行；随机 hash 碰撞极小但结果仍以实际行为为准。
