## Scope

- Version `1.2.9`, a Web behavior and presentation release. See the [changelog](../../CHANGELOG.md).
- Homepage address and subscription panels, browser language negotiation, and local time display for HTML and charts.
- `style.css`, `tools.js`, `list.js`, and `charts.js` use the `1.2.9` cache key.
- The Nginx browser-only `/announce` redirect lets the homepage select language. The native Tracker protocol, public data format, and schema need no migration.
