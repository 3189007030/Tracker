## Scope

- Version: `1.3.6`
- User-facing change: preserve IP-search results while avoiding a full seven-day observation-window sort for every search.
- Build inputs changed: `Cargo.toml`, `Cargo.lock`, `crates/tracker-model`, `crates/observatory`, and `crates/tracker-web`; the Observatory service unit carries `MemoryHigh=256M` and `MemoryMax=320M`.
- Migration / compatibility notes: no public API, table, or column change. Observatory creates an idempotent expression index on the existing public `observations` table at startup. The index is safe to leave in place on rollback.
- Changelog entry: [`1.3.6`](../../CHANGELOG.md)
