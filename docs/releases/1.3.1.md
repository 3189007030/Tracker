## Scope

- Normalize public IPv4 and IPv6 searches against literal URL hosts and each endpoint/family's most recent announce target within seven days. Canonical endpoints are returned for matching IP aliases. A shared address is evidence of a shared destination, not proof that endpoints are duplicates.
- Clear a pending list search with Escape without changing its other filters.
- Replace the detail page's capped log with 50-row pagination over a selectable 24-hour or 7-day window. Collapse unsupported/no-address-family announces by default, allow explicit expansion, and use event IDs for cross-page timeline navigation and row focus.
- State clearly that `target_ip` is the address contacted by the probe. The public projection does not contain HTTP response bodies or returned peer-address lists; the UI cannot show details that were never stored.
- Keep all public observations API fields unchanged. This is a behavior-fix patch release; the four workspace binaries are versioned `1.3.1` together.
